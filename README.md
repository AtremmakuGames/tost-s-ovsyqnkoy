# Тост с овсянкой 🍞🥣

Браузерная игра: приготовь тост с овсянкой и съешь его.

Открой `index.html` в браузере. Шаги:
1. Поджарь хлеб — останови стрелку в золотистой зоне.
2. Свари овсянку — молоко, хлопья, сахар.
3. Помешивай, пока каша не сварится.
4. Намажь овсянку на тост и добавь начинку.
5. Нажми «Съесть тост» — и смотри видео!
